# ORB + Camarilla Trading App

A trading application based on:

- Opening Range Breakout (ORB)
- Camarilla Pivot Points
- Camarilla R3
- Camarilla S3

## Current Features

- Calculate Camarilla R3
- Calculate Camarilla S3
- Basic ORB interface
- Simple trading dashboard

## Future Features

- Live market data
- Live price chart
- Automatic ORB calculation
- Buy/Sell signals
- Stop Loss and Target
- Multiple instruments
- Mobile-friendly interface
